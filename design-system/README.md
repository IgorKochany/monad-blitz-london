# CurbsidePalette

FairRide's design system. Also published as the Claude Design project
"CurbsidePalette — FairRide" (claude.ai/design).

All tokens live in [`_tokens.css`](_tokens.css) — six named colors, three
typefaces, an 8px grid, 2px ink borders, flat and hard-edged, no shadows.
Every preview below links that one file, so a change there propagates.

| | |
|---|---|
| `tokens/colors.html` | Paper / Taxi yellow / Deep blue / Stone / Ink / Olive-ink |
| `tokens/type.html` | Manrope display · Public Sans UI · Bricolage Grotesque wordmark |
| `brand/marks.html` | Wordmark, curb-stripe rule, kicker tab, ruled-grid ground |
| `components/buttons.html` | Primary / secondary / disabled / full-width accept bar |
| `components/fare-meter.html` | The countdown fare meter (signature element) |
| `components/job-card.html` | Driver job card + "quiet street" empty state |
| `components/receipts.html` | Verifiable settlement rows |
| `components/fare-split.html` | £9.00-vs-£12.00 comparison pair |
| `flows/rider-flow.html` | Rider app, end to end: set ride → bids fall → matched → in ride → pay & receipt |
| `flows/driver-flow.html` | Driver app, end to end: go online → job request → fare won → drive → paid on drop-off |

Open any HTML file directly in a browser — each is self-contained apart from
the shared token sheet and Google Fonts.
